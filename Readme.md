# BazarDor - বাজার দর

## About the Project
BazarDor is a website where users can check grocery product prices and explore different products. The main goal of this project is to make it easier for people in Bangladesh to find product prices and plan their shopping.

## Live Website
https://bazardor-owner.netlify.app/

## Technologies Used
- HTML
- CSS
- JavaScript
- React
- Next.js
- Tailwind CSS

## Features
- Users can browse different grocery products.
- Products can be explored by category.
- Users can check product prices.
- The website has a clean and user-friendly design.
- It works on desktop, tablet, and mobile devices.
- Users can easily navigate between different sections.
- The website helps users find grocery price information easily.

## How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/hridoy1337/Assignment-07.git
   ```
2. Go to the project folder:
   ```bash
   cd Assignment-07
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open `http://localhost:3000` in your browser.
